# Claude.smart
## Voice Note Studio

`voice-studio/index.html` is a browser-based voice note editor. Open it in Chrome or Firefox: no install or server is needed.

- Open a voice note (.opus, .ogg, .m4a, .mp3, .wav, .webm), drop one onto the page, or record from the microphone
- Drag on the source waveform to trim
- 24 presets: Chipmunk, Helium, Deep voice, Monster, Demon, Robot, Alien, Telephone, Radio, Megaphone, Underwater, Cathedral, Studio vocal, Podcast, Lo-fi tape and more
- Effects rack: pitch shift (±12 semitones, speed unchanged), speed change (pitch unchanged), noise gate, low cut, 4-band EQ, compressor, distortion, bitcrusher, ring modulator, chorus, flanger, tremolo, vibrato, echo, reverb (room/plate/hall/cathedral), pan, fades, normalize, reverse
- A/B against the original, loop, level meter, export to 16-bit WAV

`voice-studio/studio.html` holds the same page without the document wrapper, which is the version published as an Artifact.
